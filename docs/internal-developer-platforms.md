# Internal Developer Platforms

## Purpose

Internal developer platforms provide the curated platform capabilities that make it easier for engineers to build, deploy, observe, and operate software.

## Core Capabilities

- environment provisioning
- deployment pipelines
- service templates
- policy automation
- observability integration
- runtime support

## Design Guidance

- reduce manual platform requests
- provide paved paths for common use cases
- keep the experience consistent across teams
- make platform capability easy to discover

## Evidence To Collect

- service catalog
- onboarding flow
- template usage
- automation coverage
